# KPA1500 SmartSDR Bridge 2.50 (experimental)

**Experimental. Windows only.** The installer and helper files are Windows batch files and will not work on a Mac or Linux (those versions are still being tested).

Makes a **FlexRadio running SmartSDR** show your **Elecraft KPA1500** as a **Power Genius XL** amplifier and a **Tuner Genius XL** tuner: meters, Operate/Standby, tuner Operate/Bypass/Tune, the amp following your transmit frequency, and the tuner's C1, L and C2 bars. No serial cable needed.

Run only one bridge at a time; this one closes the [KPA1500 SDR Bridge](https://github.com/kw4ex/kpa1500-sdr-bridge/releases/latest) when it starts.

## How to download (no GitHub account needed)

1. Install **Python 3.8 or newer** from python.org if you don't have it (tick **Add Python to PATH**).
2. Look at the **Assets** list at the bottom of this page and click **Install_KPA1500_SmartSDR_Bridge.bat**. Your browser saves it, normally in your **Downloads** folder (if it warns that the file may be harmful, choose Keep).
3. Double-click it. If Windows says it protected your PC, click **More info**, then **Run anyway**. It asks a few short questions and installs into its own folder (suggested: `C:\RadioScripts`).

**Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers.

The printable guide is `KPA1500-SmartSDR-Bridge-guide.pdf` in Assets, and is also installed with the program.

To go back to an older version, open the [Releases page](https://github.com/kw4ex/kpa1500-smartsdr-bridge/releases) and download that one.
