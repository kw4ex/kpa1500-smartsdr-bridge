Raspberry Pi version EXPERIMENTAL

KPA1500 SmartSDR Bridge on a Raspberry Pi · a ready-made SD card that starts the bridge by itself

What you get

You write one file to a microSD card, put the card in a Raspberry Pi, and switch it on. About a minute later the bridge is running: SmartSDR shows your KPA1500 as a PGXL amplifier and a TGXL tuner. The Pi finds the amplifier and the radio by itself. If power is lost, it starts again by itself.

Experimental. This card image is new and has not been tested on a real Pi yet. If something does not work, see the last section. No warranty; see the end of this guide.

What you need

  • A Raspberry Pi 4 Model B (2 GB is enough), its power supply and a case. (A Pi 3B+ or Pi 5 also works.)
  • A microSD card, 16 GB or larger (32 GB, A1/A2 or "high endurance", is a good choice).
  • A computer with an SD card slot (or a USB card reader), with the Windows, Mac or Linux version of Raspberry Pi Imager.
  • Your KPA1500 and your FlexRadio on the same network as the Pi. An Ethernet cable to the Pi is the most reliable; Wi-Fi also works.

1. Get the image file

  1. Open the project's Releases page on GitHub and find the entry for the Raspberry Pi image. (While it is being tested it is not public: the owner gets it from the Releases page while signed in.)
  2. Under Assets click the file named …KPA1500_SmartSDR_Bridge_Pi_v….img.xz (the name ends in .img.xz). Save it in your Downloads folder. Do not unzip it. It is a large file (a few hundred MB).

2. Install Raspberry Pi Imager (once)

  1. Go to raspberrypi.com/software and click Download for Windows (or your system).
  2. Double-click the downloaded file and follow the installer. Open Raspberry Pi Imager.

3. Write the card

  1. Put the microSD card in your computer's slot (or card reader). Everything on the card will be erased. Copy anything you want to keep first.
  2. In Imager choose your Raspberry Pi model, if it asks.
  3. Click Choose OS, scroll to the bottom, click Use custom, and pick the .img.xz file from Downloads.
  4. Click Choose Storage and pick your SD card. Check the size carefully so that you do not pick another drive.
  5. Click Next. If Imager offers OS customisation, click No (this image has its own settings; you set them in step 4).
  6. Confirm that the card will be erased. Wait until it says the write is finished (a few minutes), then click Continue.
Windows may say "You need to format the disk in drive ... before you can use it". That is normal: click Cancel. Never click Format.

4. Put in your settings (only if you use Wi-Fi, or want your own panel password)

If the Pi will use an Ethernet cable and you are happy with a password made for you, skip to step 5.

  1. If the card's drive is gone, take the card out and put it back in. A small drive named bootfs appears (it may be the only one you can see).
  2. Open bootfs and open the file kpa-setup.txt with Notepad (or any text editor).
  3. After wifi_name= type your Wi-Fi network name; after wifi_password= type its password. Leave wifi_country=US unless you are elsewhere.
  4. If you want your own panel password, type letters and numbers after panel_password=. If you leave it empty the Pi makes one.
  5. Save the file. Eject the card (right-click the drive, Eject). When the Pi has read the file, it removes your Wi-Fi password from it.

Your Wi-Fi password is typed only into the card in your own hands. It is not part of the image on GitHub.

5. Start the Pi

  1. Put the card in the Pi (the slot is on the underside). Plug in the Ethernet cable if you use one.
  2. Connect the power supply. The red light comes on and the green light flickers.
  3. Wait two minutes the first time (it sets itself up, and joins your Wi-Fi if you filled that in).

6. Check that it works

  1. Switch on the KPA1500 and the radio, and start SmartSDR. Within about 20 seconds SmartSDR shows the PGXL and TGXL.
  2. Open a browser on any computer on your network and go to http://kpa-bridge.local:8080. The panel asks for the password and shows the amplifier meters and buttons.
  3. Where is the password? Take the card out later and open KPA_Bridge_Info.txt on the bootfs drive. It holds the full panel address with the password in it, and it is refreshed at every start. (If you typed your own password in step 4, it is that one.)

Updating the bridge later

  1. Download the new kpa1500_sdr_bridge.py and kpa1500_flex_emulation.py from the project.
  2. With the card in your computer, make a folder named update on the bootfs drive and put the two files in it.
  3. Put the card back in the Pi and start it. It copies the files in, restarts the bridge and renames the folder update_done_….

If something does not work

ProblemTry this
No PGXL/TGXL in SmartSDR after 3 minutesIs the Pi connected to the same network as the radio (Ethernet cable plugged in, or Wi-Fi joined)? Open http://kpa-bridge.local:8080; if that page does not open, the Pi is not on your network.
kpa-bridge.local does not openUse the address line in KPA_Bridge_Info.txt (it shows the Pi's number address), or look for "kpa-bridge" in your router's device list.
Wi-Fi did not connectCheck the name and password in kpa-setup.txt (capital letters count) and try again, or use an Ethernet cable once. A 5 GHz-only network needs the right wifi_country.
The amp is not foundSwitch it on (not asleep) and check its network cable and that it is on the same network.
Nothing happens at allRe-write the card (step 3). If it still fails, keep the card, and send KPA_Bridge_Info.txt and what you saw to the project's Issues page.
Only one bridge at a time. If you also run the bridge on a PC or Mac, close it first. Two bridges fight over the amplifier.
