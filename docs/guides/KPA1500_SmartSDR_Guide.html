KPA1500 SmartSDR Bridge EXPERIMENTAL

Version 2.51 · Design and on-air testing by KW4EX · Guide for operators, not programmers

1. What it does

This program makes a FlexRadio running SmartSDR see your Elecraft KPA1500 as two Flex accessories:

  • a Power Genius XL (PGXL) amplifier: meters, Operate/Standby, and the amp following your transmit frequency;
  • a Tuner Genius XL (TGXL) tuner: Operate, Bypass and Tune buttons, return-loss and forward-power meters, and the C1, L and C2 bars of the KPA1500's built-in tuner.

The bridge runs on a computer on your home network. It talks to the amplifier over the network and to the radio over the network. No serial cable is needed.

Experimental. This is new and has been tested on one station. Keep a hand on the amplifier and watch your first transmissions. It is shared as is, with no warranty (see the end of this guide).

2. What you need

  • A KPA1500 on your network (cabled to your router) and switched on.
  • A FlexRadio running SmartSDR, on the same network.
  • A computer that stays on while you operate: Windows 10 or 11 (tested), or a Mac, Linux PC or Raspberry Pi (not yet released; see section 4).
  • Python 3.8 or newer. The Windows installer tells you if it is missing.
Run only one bridge at a time. The KPA1500 SDR Bridge (for Thetis and NereusSDR) and this one both control the amplifier. Each closes the other when it starts. Do not use this together with the Zeus KPA1500 add-on.

3. Install on Windows

  1. Open the Releases page of the project on GitHub (the README has the link). The top entry marked Latest is the newest version.
  2. Under Assets click Install_KPA1500_SmartSDR_Bridge.bat. (Do not click "Source code".) If your browser warns that the file may be harmful, choose Keep.
  3. Open your Downloads folder and double-click the file. If Windows says it protected your PC, click More info, then Run anyway.
  4. Answer the questions. Press Enter to accept the answer shown in [brackets].
    • Folder: the suggested C:\RadioScripts is fine. The bridge gets its own subfolder, KPA1500_SmartSDR_Bridge.
    • Amplifier: choose 1 (search) with the amp switched on. If it is not found, choose 2 and type the amp's IP address.
    • Radio: choose 1 (search). If the search ever fails on your network, choose 2 and type the radio's IP address.
    • Shortcuts and firewall: say yes to the Desktop shortcut and to opening the firewall ports. Windows asks you to confirm.
  5. At the end say yes to Start the bridge now. A small bridge window opens. Leave it open.

Upgrading: run the new installer over the old one. It offers to keep your settings and saves the old program files as .bak copies.

4. Install on Mac, Linux or Raspberry Pi NOT YET RELEASED

An installer for these is being tested. It is not on the Releases page yet. When it is, the steps are:

  1. Download Install_KPA1500_SmartSDR_Bridge.sh.
  2. Open Terminal and type bash (with a space), drag the file into the Terminal window, press Enter.
  3. Answer the same questions as on Windows. The suggested folder is RadioScripts in your home folder.
  4. Say yes to start automatically. On Linux and the Pi this installs a service that restarts the bridge if it stops. On a Mac it adds a login item.
Mac note: a sleeping Mac stops the bridge, and a closed lid on battery power puts it to sleep. For an always-on bridge, a Raspberry Pi is the robust choice.

5. First run in SmartSDR

  1. Switch on the amplifier and the radio, and start SmartSDR.
  2. Start the bridge (Desktop shortcut or start_kpa_smartsdr_bridge.bat).
  3. Within about 20 seconds SmartSDR shows the PGXL and TGXL in its accessory panels, and the Applet window of the bridge shows Flex: <your radio>.
  4. To check, open http://127.0.0.1:8080/flex in a browser on the bridge computer. It shows the radio login and meters.

6. Using it

In SmartSDRWhat happens
Amp Operate / StandbyThe KPA1500 switches to the same state.
Tuner Operate / BypassThe KPA1500's tuner is put in line or bypassed.
Tuner TuneStarts a tune. Press Tune again to cancel. In Standby the bridge refuses to tune.
Change band or frequencyThe amplifier follows the transmit slice by itself.

The bridge also has its own browser panel and a small Applet window (Open_Applet.bat) with the meters and buttons.

7. Settings

Open start_kpa_smartsdr_bridge.bat (Mac/Linux: start_kpa_smartsdr_bridge.sh) with Notepad or a text editor. The settings are at the top.

SettingMeaning
AMP_IPauto searches for the amplifier. Or type its address.
FLEX_RADIO_IPauto searches for the radio. Type an address to skip the search. Leave empty to not log in to the radio.
FLEX_RADIO_FALLBACK_IPUsed only if the search finds nothing.
FLEX_INTERLOCK1 makes the radio wait for the amp before it transmits (experimental). Default 0.
FLEX_VERBOSE1 logs every message to and from the radio. Use it when something does not work.

Save the file and start the bridge again. To stop it: Stop_Bridge.bat, or press Q in the bridge window.

8. Over-drive protection

Too much drive into the amplifier can damage it. This protection watches the drive going into the KPA1500 and acts when it is over a limit you set. It helps; it does not replace care. The amplifier's own protection stays the last line of defence.

SettingMeaning
Limit (W)One overall limit for the drive into the amplifier. Empty, 0 or off = protection off.
If it goes overIgnore: nothing. Warn: a red message (panel bar, Applet banner, status line, log); nothing is changed. Hold at the limit: the same warning, and the bridge puts the radio's RF power setting back to the limit before you transmit. If the measured drive still stays over the limit for about 1.2 seconds more, the amp is put in STANDBY and stays there until you lower the drive and press OPERATE.
Radio full power (W)The radio's RF power setting is a percent of its full power. Default 100 (most FlexRadios). Used to turn the setting into watts.

Where to set it

  1. Open the bridge's browser panel (http://127.0.0.1:8080), click the gear (Settings) and find Over-drive protection. Or open the Applet window and choose Look, then Safety: over-drive protection.
  2. Type the Limit in watts, for example 80.
  3. Choose If it goes over: Warn is a good first choice.
  4. Check Radio full power. Leave it at 100 for a 100 W radio.

A new install starts with Warn and no limit, so nothing happens until you type a number.

Good to know
  • It only works while the amp is in OPERATE. In STANDBY, and while the amp tunes its own ATU, the limit is ignored on purpose, so you can tune with full radio power.
  • Only the amp's own input-power reading is judged. Short peaks (under 0.8 second) are ignored, and the drive must be about 10 % + 1 W over the limit before it counts: that margin is on purpose.
  • The bridge changes the radio's RF power at most once every 1.5 seconds, so it does not fight SmartSDR or you.
  • The radio's TUNE power is not changed. A tune through the amp in OPERATE is still judged by the measured drive.

9. If something does not work

ProblemTry this
SmartSDR shows no PGXL or TGXLIs the radio switched on and on the same network? Run KPA_Network_Check.bat. Make sure the firewall ports were opened (TCP 9008, TCP 9010, UDP 4992). Type the radio's address into FLEX_RADIO_IP.
The amp is not foundSwitch it on (not asleep) and check the network cable. Type its IP address into AMP_IP.
Meters are blankWait 20 seconds after SmartSDR starts. Restart the bridge.
Tune does nothingThe amplifier must be in Operate, not Standby.
Amp does not follow frequencyIt follows the radio's transmit slice. If Thetis or TCI is also running, the Thetis connection takes over.
Over-drive protection says it is waitingIt only works while the amp is in OPERATE. In STANDBY, and while the amp tunes its own ATU, the limit is ignored on purpose.
The radio's RF power setting is never readThe bridge must be logged in to the FlexRadio (the Applet shows Flex: ...). The measured-drive check still works without it.
"Address already in use"Another bridge is running. Close it, or just start again: the start file closes an older bridge first.

For more detail, set FLEX_VERBOSE to 1, reproduce the problem, and look at kpa1500_bridge.log in the install folder.

10. Uninstall

  1. Double-click Uninstall_KPA1500_SmartSDR_Bridge.bat in the install folder (Mac/Linux: uninstall_kpa_smartsdr_bridge.sh).
  2. It stops the bridge and removes the shortcuts, the firewall rules and the auto-start entry.
  3. When asked, answer y to delete the bridge's own files. It never deletes the folder or anything else in it.
